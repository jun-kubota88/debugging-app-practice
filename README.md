## 概要
COACHTECH 教材 Tutorial 10-4「デバッグ ハンズオン演習」で作成した成果物です。

## 使用技術
- PHP 8.x
- Laravel 10.x
- デバッグツール（`dd()`, `dump()`, `Log` ファサード）

## 学んだこと
- エラーメッセージから問題箇所を特定する読み解き方
- dd() と Log::info() を使い分けたデバッグの進め方
- Mass Assignment エラーと $fillable の役割
